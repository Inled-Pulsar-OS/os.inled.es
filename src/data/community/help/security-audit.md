We want independent eyes on the packages that ship in the default image.

**What we need:**
- Review the package list for anything that shouldn't be there.
- Check that every package has a known maintainer.
- Compare the shipped binaries against upstream sources.
- Report anything suspicious in the linked issue.

You do not need to be a security expert — a careful review is already
valuable. All findings are published and credited.
