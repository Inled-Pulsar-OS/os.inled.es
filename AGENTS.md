## Development

When starting the dev server, use background mode:

```
astro dev --background
```

Manage the background server with `astro dev stop`, `astro dev status`, and `astro dev logs`.

## Where things live

This site is the umbrella index for the Pulsar OS editions. Documentation is
not hosted here: it lives at https://help.inled.es/docs/pulsar-os/, and the
old `/help/*` URLs 301 there via `public/_redirects`. The community pages were
removed; `/community*` 301 to the Discord invite. Bitten Fruit has its own site
at https://bittenfruit.inled.es, with `/bitten-fruit` kept here as an on-site
overview.
